# SMTC Player

Плеер для Rainmeter поверх **Windows SMTC** (Global System Media Transport
Controls) — того же системного канала, что рисует оверлей громкости с обложкой.
Поэтому он работает с любым приложением, которое туда репортит: Яндекс Музыка,
Spotify, браузеры, VLC. Штатный плагин `NowPlaying.dll` Яндекс Музыку не
поддерживает — отсюда своя прослойка.

Оформление — в языке набора Mond: Aquatico + Quicksand, белое на прозрачном,
тонкая линия прогресса. Обложка — квадрат сверху по центру, углы скруглены
маской `@Resources\CoverMask.png`. Когда картинки нет (нет сессии или плеер не
отдал миниатюру), она убирается совсем, а всё, что ниже, подтягивается вверх на
её высоту — карточка становится компактной, без пустого места. Двигает вёрстку
переменная `CoverShift`, её шлёт мост.

## Как это устроено

```
smtc_bridge.exe            Rainmeter
 ├─ читает Windows SMTC
 ├─ !SetVariable ──WM_COPYDATA──▶ Player.ini (Title, Artist, Position, …)
 └─ cmd.ini ◀──!WriteKeyValue─── клики по кнопкам
```

Мост — фоновая утилита (~30 МБ, окна нет). Скин поднимает его сам при загрузке
(`[MeasureBoot]`), вторая копия отваливается по мьютексу, а сам мост выходит,
если Rainmeter не запущен дольше минуты. Раз в 5 секунд он шлёт все значения
принудительно: после `Refresh` скин откатывает переменные к дефолтам.

Данные лежат в `%LOCALAPPDATA%\RainmeterSMTC`:

| Файл | Что это |
|------|---------|
| `nowplaying.txt` | текущее состояние, 9 строк — для отладки и сторонних потребителей |
| `cover0/1.png` | обложка трека, файлы чередуются — иначе Rainmeter отдавал бы закэшированную картинку прошлого трека |
| `bridge.log` | лог моста |

Канал команд — `Player\cmd.ini`, **внутри папки скина**: `!WriteKeyValue`
отказывается писать за пределы каталога скинов. Путь к нему мост получает
аргументом `-CmdFile` при запуске из скина.

## Управление

- **⏮ ⏯ ⏭** — предыдущий / пауза / следующий
- **клик по линии прогресса** — перемотка
- **колесо мыши** — масштаб скина

## Сборка

Пакет целиком:

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1            # мост + .rmskin
powershell -ExecutionPolicy Bypass -File build.ps1 -SkipBridge # только упаковка
```

Только мост:

```powershell
powershell -ExecutionPolicy Bypass -File "Skins\SMTC Player\@Resources\Bridge\src\build.ps1"
```

Нужен `csc.exe` из .NET Framework 4 (есть в любой Windows) и `Windows.winmd` из
Windows SDK (`C:\Program Files (x86)\Windows Kits\10\UnionMetadata`).

`tools\deploy.ps1` кладёт скин из репозитория в папку Rainmeter и перезагружает
его — так проверяются правки без пересборки пакета.

Формат `.rmskin` — обычный ZIP плюс 16 байт хвоста: `uint64` с размером
ZIP-части, байт версии формата и строка `RMSKIN\0`.

## Настройки

`@Resources\Variables.inc`:

- `TextColor`, `ButtonColor`, `ButtonHover`, `DimAlpha` — цвета
- `PreferApp` — если задать AppId (например `ru.yandex.desktop.music`), плеер
  будет показывать только его. Пусто — показывает текущую системную сессию, а
  если та на паузе, переключается на ту, что реально звучит.

`PreferApp` уходит мосту аргументом при старте, поэтому после правки нужно
перезагрузить скин — мост подхватит новое значение вместе с ним.

## Грабли, на которые уже наступили

- **`AppVersion` в `[Rainmeter]`** кодируется как `major*1000000 + minor*1000 +
  patch`. `4050000` — это «требуется 4.50», такой версии нет, и Rainmeter молча
  выгружает скин через секунду после загрузки.
- **`.ini` и `.inc` с кириллицей должны быть в UTF-16LE.** В UTF-8 с BOM
  Rainmeter 4.5 молча не подхватывает `@include` — переменные остаются
  неразвёрнутыми (`#DataDir#` так и попадает в путь).
- **WebParser не читает локальные файлы**: `file://` уходит в WinInet, который
  этот протокол не поддерживает (ошибки 12006 / 53). Поэтому данные пушатся
  бэнгами, а не опрашиваются из файла.
- **Действия секции `[Rainmeter]`** (`OnRefreshAction` и т.п.) выполняются
  раньше, чем подхватываются переменные из `@include`.
- **`!WriteKeyValue` не создаёт файл** — только пишет в существующий. `cmd.ini`
  создаёт мост при старте.
- **`!WriteKeyValue` пишет только внутрь каталога скинов.** Путь в
  `%LOCALAPPDATA%` даёт `Illegal path`, и кнопки молча перестают работать —
  отсюда `cmd.ini` рядом с `Player.ini`, а не рядом с остальными данными.
- **Формулу вида `(72+-72)` Rainmeter не переваривает** — метр молча не
  рисуется. Поэтому `CoverShift` приходит положительным и вычитается.
- **Любой `.ini` в папке конфига Rainmeter считает отдельным скином.** Канал
  команд с именем `cmd.ini` он подхватил вместо `Player.ini` и написал «скин не
  содержит мер, будет деактивирован». Поэтому файл называется `cmd.inc`.
- **Установщик закрывает Rainmeter и переносит папку скина в `@Backup`.**
  Запущенный `smtc_bridge.exe` внутри этой папки делает перенос невозможным
  («Unable to move to …»), установка падает, а Rainmeter остаётся закрытым.
  Поэтому мост при старте копирует себя в `%LOCALAPPDATA%\RainmeterSMTC` и
  работает уже оттуда, а экземпляр в папке скина живёт доли секунды.
- **Копия поднимается отвязанной** (`DETACHED_PROCESS` +
  `CREATE_BREAKAWAY_FROM_JOB`), чтобы её жизнь не зависела от того, как
  Rainmeter обходится с запущенными из скина процессами.
- **Позиция трека приходит снимком**, а не потоком: Яндекс Музыка обновляет
  timeline по событиям. Мост доводит её сам от `LastUpdatedTime`.
